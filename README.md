# FLoRA × Wikipedia: early demo pages

Static demo pages from the first stage of the FLoRA Wikipedia audit (a DOI screen
and a replication-gap overview). They are kept here for reference and are no
longer maintained. The audit code, data and the current review-card prototype
live in [forrtproject/flora-wikipedia](https://github.com/forrtproject/flora-wikipedia).

Served at https://lukaswallrich.github.io/flora-wikipedia-demo/.
